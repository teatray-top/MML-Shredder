# YDP Grand Piano

`YDP-GrandPiano-20160804.sf2` is the unmodified **YDP Grand Piano** SoundFont,
release **2016-08-04**, distributed by the FreePats project.

The source recordings are **Zenph Studios Yamaha Disklavier Pro Piano
Multisamples for OLPC**, performed and recorded by **Dr. Mikhail Krishtal and
his team at Zenph Studios**. **Roberto (roberto@zenvoid.org)** produced the
SoundFont and modifications to the original samples for FreePats. The samples
were donated to **Dr. Richard Boulanger at cSounds.com** for the OLPC sound
sample library.

MML 세단기 embeds this bank as its default preview piano; the source SoundFont
is excluded from Git. Building from source requires this file at
`assets/soundfonts/YDPGrand/YDP-GrandPiano-20160804.sf2`. Release executables
need no external SoundFont or VST installation. The release includes this
README and the original attribution and license in `docs/piano`.

The bank has one piano preset (bank 0, program 0), five velocity layers, and
121 unique mono 44.1 kHz recordings. Note regions cover MIDI keys 20–109 and
use natural recorded decays without sample loops. No sample recordings have
been edited. Preview output is mono and does not change the saved MMI.
